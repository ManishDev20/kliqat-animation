# KliqAt Product Film

A code-based product animation for **KliqAt — the all-in-one workspace for photographers**.

## Creative direction

- 18-second premium product film
- 5-second prototype composition included
- Black + white base with purple accent
- Poppins-style editorial typography
- Real KliqAt product screenshots; no fake UI recreation
- CN FILMS PHOTOGRAPHY is treated only as contextual product data inside the supplied screens

## Run locally

```bash
npm install
npm run dev
```

Render the prototype:

```bash
npm run render:prototype
```

Render the full film:

```bash
npm run render
```

## Screenshot assets

The Remotion project references four product screenshots in `public/screenshots/`. The GitHub connector cannot directly commit binary conversation images, so download the supplied **KliqAt screenshot pack** and copy the JPGs into that folder using the names documented in `public/screenshots/README.md`.

Once those assets are present, the repo is clone-and-run.
